# 📊 SQL Data Analytics Project  
## Database: ClassicModels (MySQL)

### 📌 Overview
This project demonstrates practical SQL skills using the ClassicModels relational database. The objective was to perform structured data analysis, generate business insights, and optimize query performance using MySQL.

### 🎯 Objectives
- Extract and analyze transactional data
- Perform customer and revenue analysis
- Apply relational joins for multi-table insights
- Use aggregate functions for business metrics
- Implement subqueries for advanced filtering
- Create views for reusable reporting
- Optimize queries using indexes

### 🛠 Tools & Technologies
- MySQL Server
- MySQL Workbench
- GitHub

### 📊 Key Analysis Performed
- Customer order frequency analysis
- Revenue and payment trend analysis
- Average product pricing insights
- Customer payment aggregation
- Performance optimization using indexing

### 🚀 Skills Demonstrated
- Strong understanding of relational database concepts
- Writing optimized and structured SQL queries
- Data aggregation and grouping techniques
- Query performance tuning using indexes
- Creation of reusable analytical views
